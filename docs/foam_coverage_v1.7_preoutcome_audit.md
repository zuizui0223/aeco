These raise trait-provenance uncertainty, not proof that every historical Microhylidae code is wrong. PDF page screenshots requested but cache misses; extracted text used. For annual screen require >=72 total each as necessary condition for >=6 years with >=12 dated records each; obtain annual facets and preserve changed index counts, zeros, failures. Stronger >=24 per group/year sensitivity. Freeze all previously unsampled passing cells before retrieving joint year-month outcomes; minimum 20 new cells/5 blocks before claiming temporal-model feasibility. Thresholds are analyst-defined screening choices, not biological power or fertilization evidence.
